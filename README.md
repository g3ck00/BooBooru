# BooBooru

BooBooru is a simple multimedia viewer for Danbooru on Windows.

Given the lack of a program of this type for Windows (they prioritize Android too much!), I took it upon myself to create it (I'm a C# beginner!), so it's a personal project, but I thought I should share it anyway, in case it might be useful to someone. It's just a prototype, and I plan to add many more features.

Click HERE to download the .exe.

Pending features:

* Increased compatibility with other boorus (Danbooru was just a starting point!)
* Improved multimedia viewer (arrow navigation, GIF and video viewer).

* Settings panels.

* Visual enhancements.

* Among others...

As I said, C# isn't my strong suit, but I'll be attentive to any feedback.
