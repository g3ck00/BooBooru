# BooBooru

BooBooru is a simple media viewer for Danbooru on Windows.

Given the lack of a program of this type for Windows (Android prioritized too much!), I chose to create it by myself (I'm a C# beginner!), so it's a personal project, but I thought I should share it anyway, in case it might be useful to someone. It's just a prototype, and I plan to add many more features.

Click HERE to download the .exe.

Pending features:

* Increased compatibility with other boorus (Danbooru was just a starting point!)
* Improved media viewer (arrow navigation, GIF and video viewer).
* Settings panels.
* Visual enhancements.
* Among others...

As I said, C# isn't my strong suit, but I'll hearing any feedback.
